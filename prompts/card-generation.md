# 独立闪卡模块

只执行 [references/quality-workflow.md](../references/quality-workflow.md) 的美术工作流，接口见 [CARD.md](../CARD.md)。不写星系内容，不改已冻结人物文字；已有有效偏好继续使用，不发审美问卷。

向图像工具发送的是已选定的主体、动作/结构、材质、配色、光线与构图，外加本层职责、同原型参考、真实画布与透明设置；不是这份执行手册。程序 `cardgen.py` 可从结构化设计编译具体视觉 prompt。

阶段顺序：真实无字原型 → 实际看图并通过 → 原生独立层 → 无字合成对照 → 独立排字 → 最终景深/foil/手机检查。不要为凑层数牺牲主体质量，不按技术名词堆工程符号。用户未指定风格时内部比较两三个方向，只选择一个主导视觉语言。

缺图像工具就缺绘画能力，不能用代码几何图或 PNG 扩展名伪装。来源记录使用真实工具返回；复用必须明确同主人和复用范围。未验卡是候选，不是完成。修失败层，保留合格层与成功 HTML；卡片合格后交 public `run --layers` 自动接入，无需用户再次请求。
