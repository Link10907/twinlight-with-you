# 内部提示词：独立闪卡模块

## Scope

只制作当前用户的原生分层闪卡、便携卡包和独立预览。可被默认一次请求入口调用，也可在用户明确只要卡片时独立运行。无需星系页面，不整理 themes，不构建星图 HTML；不修改上游已校验的昵称、总结者、称号、关键词或叙事。执行接口见 [CARD.md](../CARD.md)。

默认入口先取得可用基础 HTML，再调用本模块；本模块成功后入口自动接入匹配卡包并交付两份结果，用户不发第二条命令。HTML 失败也不能阻止独立卡片完成或使其素材丢失。

## Inputs

- 当前 validated 只读 Lite 数据；明确单做卡片时也接受 `card-1`，无需 themes。Strict 使用按原有流程审核的只读 analysis / compiled persona，不转换成另一个 Lite 绑定。
- 当前 owner、独立卡片目录、实际 persona_digest 与真实确认状态。Lite 可先做未确认私人草稿，不能伪造确认；Strict 保留原审阅要求。
- 独立 `card/art-brief.txt`，或 Strict 的 `art-direction.json` / 派生 art-brief；用户明确提示与可见参考优先。美术设置不注入 HTML 内容，不改变人物绑定。
- 当前原型、实际构图锁与已合格原生层（如已有），以及本次真实可调用的图像、排字、文件与独立预览能力。仅复用同一主人和获授权工件；宿主能写文件或运行 Python 不代表能生成绘画。

## Outputs

- 当前无字 3:4 prototype 与锁定的实际宽高、构图。
- 原生图层及绑定 `layers.json`：完整 background、真实透明 subject / effects / 可选 spirit、同像素 lineart、准确程序 text。
- 便携 `card.json`、只展示卡片且有真实景深与 foil 的 `preview.html`、已有素材合成的正面 `front.png`。PNG 不烘焙动态 foil，不能替代互动预览。Strict 无实际截图能力时如实说明 PNG 缺失，仍保留其原生卡包与独立预览。
- 实际机械、视觉和交互检查；未运行的标未验证。原型或占位属于未完成卡片的预览，不能生成假原生卡包或宣布完整闪卡完成。
- 简短生成记录：本次工具调用/返回工件标识或路径、实际使用的原型与各层、修改和选择原因，以及实际看图/互动检查结果。记录用于核对发生了哪些步骤，不伪造工具返回或把原型重复登记成独立层。

完成素材交给入口自动调用 [HTML 模块](html-build.md) 接入；卡包既是独立交付，也可作为内部接口。用户直接看到卡片与预览，不需要理解 JSON。

## 验收

按 [美术契约](../references/art-direction.md) 执行。用户明确风格和最新反馈优先，未指定部分由 AI 内部比较少量设计方向并选定；保证整幅作品的画风、材质、动作、比例、光线和卡面可读性，不用同一模板脸或同一只鹿。

素材缺失时，必须实际调用图像工具生成无字、无框、无预烘焙闪光的原型，再用同一原型直接生成原生层，锁定实际画布和坐标。不能用代码绘制简单几何形、模板占位或静态 SVG 来冒充专属绘画或完整 SSR；程序排字、边框、同像素线稿与装层仍按接口执行。透明层启用真实透明输出，禁止抠图、去绿幕、棋盘转 alpha、裁切、缩放和重摆。SSR 与当前文字由程序准确独立排版，text depth=0；lineart 从最终 subject 同像素派生。

运行 validate-art 并实际比较原型、各层与 front：背景没有第二主体，主要物件不重复，alpha 干净，主体配准，焦点清楚，文字逐字准确且不遮挡。保留实际返回文件与简短视觉记录；机械通过只能说明像素/结构检查，不能证明工具确实生图、绘画完成度或与原型配准，不能代替看图。

在独立 preview.html 中检查左右视角、关闭 foil 后的层内景深、视角驱动闪光、文字固定、拖动与翻面、触摸/键盘和减少动态，保留实际检查结果或截图。此验收不等待星系 HTML；实际浏览器能力不足时说“文件已生成，动态未验证”，不能把静态 PNG、卡包齐全或预览文件创建当动态通过。文件完成与完整视觉/互动验收分别报告，不要求用户再确认才能完成当前私人草稿。

## 仅重试当前模块

保留上游只读数据、人物绑定与合格层。生图失败只修失败层，首次生成后每层最多再生成两次；装层、字体、路径或预览问题只修对应技术步骤。达到上限时，仅在美术契约允许的条件下做一次明确构图修订，保留原素材与记录，不放宽旧锁或改文案凑通过。

仍无法完成时保留静态或占位预览，明确分层闪卡未完成，并保留入口已经验收的 HTML。没有真实图像工具时直接说明该能力缺口，不编造生成记录或代码画图凑成功；HTML 缺口也不阻止本模块独立制作。无授权照片时称原创概念，不称本人肖像；generated 不等于本人 approved。不启动无限生图、自动付费 API，也不把另一人的素材当兜底。

完成卡片后不修星系页面：导入或构建错误由 HTML 模块处理，已完成的卡包与独立预览保持可用。发布仍另需本人明确授权。
