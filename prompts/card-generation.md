# 绘画执行者的单一入口

先读 `CARD.md` 与 `references/visual-contract.md`。用当前 `art-direction-2` 与 `assets/art-styles/catalog.json`，不要把旧版自由选择提示当作当前生成入口。

只发实际编译的视觉任务，不发这份手册、聊天记录、能力评分或完整网页要求。每次包含固定风格、该层具体内容、相同构图和原型参考。人物描述是“谁、什么物种、怎样的外貌、衣服、神情、动作、一个道具”，不是“拆解、共创、成长”。

先无字原型，实际审查通过，再生成完整背景/原生透明主体/少量原生透明前景。原型不是最终层；主体遮住的背景要完整。主体接触的物件保留同层，不人为拆开手与道具。

每次实际返回立即用 visual_plan record 保存原字节与实际响应，再审查。没有参考图、alpha 或合法 native canvas 时明确缺能力；Python 画图、截图切片和补边不是替代路线。

不负责星图页面设计，不改变当前人的文字，不生成 HTML 效果图。成功图层只交给既有装层器、public run 和导出器；完整成品由这些关口共同确定。
