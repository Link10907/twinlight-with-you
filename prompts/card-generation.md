# 图像执行者入口

按 [CARD.md](../CARD.md) 执行当前卡片任务。默认保留 `twinlight-collector` 与其实际视觉参考；用户明确换画风才覆盖。一个主体与清楚动作可以拥有精细材料、丰富环境和充足纵深，不等于极简插图。

每次只向图像工具发送已编译的任务 prompt 和真实参考图。原型任务的 `style_only` 只借视觉语言；层任务仅使用当前原型作 `composition` 编辑画布，保留视野、姿态、尺度、坐标和光线，不重新生成一张居中立绘。参考路径没有被工具读到，就不算传入。

先无字原型，实际与参考比较完成度；通过后用图像工具原生编辑同一原型，保留指定层、移除或补全其他部分，输出完整背景、透明主体和少量透明前景。背景需移除指定近景，避免和effects重叠。真实返回立即登记原图与响应。程序承担精确文字、卡框、lineart 与效果，图像执行者不改个人文案，不设计网页。

缺参考或原生透明能力时报告实际缺口。代码几何插画、重复海报、截图切片、裁剪和补边都不是这条生产链的替代品。

调用前先获得本轮独立 image dispatch；实际接口不接受 prompt 或参考参数时，不往弃用字段塞值。只有真正隔离的任务上下文能替代显式 prompt。没有隔离能力就报告 capability_blocked，禁止继续从网页图中裁出小卡。
