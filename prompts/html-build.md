# 固定 V10 HTML 组装模块

消费已校验的当前人内容和合格原生卡包，使用完整项目的固定 V10 模板。必须保留星系首页、行星接近、AI 星系介绍、连续交融、提问转场、揭卡、翻面和返回体验，不能自行写另一个 React/Canvas 页面或用截图替代 HTML。

完整资源下载失败时，先从当前离线 skill 包或完整仓库恢复并验证；仍不可得就报告资源缺口。即使把文件标成 candidate，也不能手写一份简化网页冒充原模板的进展。

基础 `site/index.html` 可以先成功。成品卡到位后，通过相同 public `run --layers` 构建 `site-with-card/index.html`，校验模板来源、两份 persona、真实内嵌六层字节和同卡正面图，并跑当前 HTML 浏览器检查。实际看首页到揭卡的关键画面，完整播放交融，不只用跳过按钮。

both 的 `primary_output` 必须是 `html_with_card`。脚本、纹理、音乐与图像在单文件中自包含；HTML 不含字体文件、聊天原文或工具响应。不能通过替换 data URI、修改 art_status 或更新模板锁掩盖差异。

public 报告完成后用 `deliver_artifacts.py` 导出相同文件。宿主内预览与本地浏览器通过分开记录；WebGL 降级、声音首次需点击等实际限制照实说明。未通过只修失败模块，保留已完成的独立卡片与页面。
