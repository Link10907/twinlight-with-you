# 美术设计说明

当前生产入口是 [CARD.md](../CARD.md)，字段是 [art-direction-2 视觉契约](visual-contract.md)，实际看图标准是 [V10 品质标准](quality-workflow.md)。本文件保留兼容链接，不再维护另一条绘画流程。

先保留用户已认可的 Twinlight V10 质感。默认 `twinlight-collector` 的精细幻想收藏卡风格，读取随包 `style_only` 参考；只有明确换画风请求才选择其他方向。参考的线条、材质、光线、层次和完成度可复用，旧人的形象和经历不套用。具体主体和动作来自当前人的授权资料，不从称号机械联想一堆符号。

用户要求研究其他美术方向时，再找可实际观看的作品并选择一个主方向；不把搜索摘要当已经看图，不把四个风格菜单强加给每一次生成。沿已选方向完成原型、原生层和最终效果，不在流程中任意换画法。

所有 native 层用图像工具原生编辑同一已通过原型，保留完整视野、画布与坐标。仅原型阶段附品牌审美参考；层阶段以该原型为唯一 composition 参考，不重新设计人物。禁止的是程序抠图、去底或几何变换，允许图像工具用原生透明开关编辑当前原型。旧自由 brief、`art-direction-1` 与历史 `art-brief` 命令只用于读取旧资料或诊断，不取代当前 public `run` 的 v2 入口。
