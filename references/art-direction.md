# SSR 卡：先原型，直接生成独立图层

Lite 和严格模式使用同一个生图契约。目标是 RuiC 参考中的紧凑层内景深：背景、主体、少量前景在同一张卡里相对移动，文字固定；不能只把整幅海报倾斜或向外摊开。

## 个人设定与原型

内容依据本次已确认材料生成，不参考作者、demo 或其他人的经历与形象。提取一个核心行为隐喻和最多两个轻细节；不把所有兴趣堆成徽标。本次 `art_prompt` 的形态、场景、画风与配色优先；主体可以是人物、物件或抽象象征，不强行加入人像。仅在未指定美术风格时默认细腻轮廓与厚涂的精致幻想 2D 画法，不默认月夜、金色场景、性别或职业服装。

没有授权照片则标明原创概念角色，不虚构本人长相；有照片时仅按授权使用，不擅自改变关键特征。SSR 对所有人固定，不生成战力、概率或能力排名。实际署名取本次总结者，而不是导出来源。

先直接生成一张**无字、无卡框、无预烘焙镭射**的 3:4 `prototype.png`。推荐统一 1080×1440 或等比例 3:4，采用图像工具实际支持的尺寸。原型锁定主体姿态、画布坐标、配色、场景与前景元素；它是后续生成的图片参考，不是待抠图的素材。

## 原生分层契约

把原型及对应 prompt 交给实际可用且获授权的图像工具；以最少视觉信息代替历史原文。Lite 使用 `card-spec` / `next` 的 prompt；strict 使用 `art-brief` 绑定经审查的 persona，并遵循相同图像步骤。

所有层尺寸与坐标一致。直接生成每一层，不从原型技术抠图或裁切重摆。主体、特效与中景调用必须启用图像工具的真实透明背景；灰白棋盘格不是透明。工具返回绿幕、不透明主体、伪透明或另一比例时请求重生成，不能自动转 alpha 兜底。不可用工具名称、付费 API 和缺失能力必须如实报告。

| 层 | 内容 | Alpha | 默认 depth |
|---|---|---|---|
| background | 根据原型直接生成的完整场景，不含主体或其残影，遮挡处也完整 | 完全不透明 | −0.25 |
| subject | 同原型姿态、尺寸与位置的主体及主要手持物 | 原生真实透明 | +0.40 |
| effects | 少量独立前景花瓣、纸页或光线，避免遮脸 | 原生真实透明 | +0.50 |
| spirit | 可选次要角色或中景象征物；不用则空透明层 | 原生真实透明 | +0.10 |
| lineart | 从最终 subject 的同一像素派生轮廓，不重新生成主体 | 白底暗线 | 跟随主体 |
| text | 程序独立排版 SSR、昵称、称号、关键词、边框与署名 | 真实透明 | 0，不视差 |

程序排字可保证中文与 SSR 准确；文字在独立 text 平面上，与参考 skill 的做法一致。不是把卡名写进生图，再靠一整张图片倾斜。保留标题安全区，独立前景避免盖住脸和关键手持物。

按 `examples/layers.example.json` 的结构保存 `card/layers.json`；不要复用示例值。manifest 的 `persona_digest` 必须绑定当前人的卡片规格。原型可另存作为构图参考，但不能复制到 subject、effects 和 spirit 上凑层数。

## 状态与视觉检查

- `layered`：确实存在独立原生层。`generated` 表示有素材，视觉与本人确认完成才可标 `approved`。
- `static`：只有完整原型时可以展示静态插画，内部 depth 为 0；不声称独立景深。
- `placeholder`：没有图像能力或素材；星盘占位只用来预览页面，不代表个人卡已经完成。

运行 `validate-art`，检查同尺寸、真实 alpha、文件完整性与绑定。若主体边缘与原型不匹配或工具偷偷裁画布，重新生成对应层；不裁剪主体纠正。程序检查不能证明构图协调、身份准确或背景没有残影，还需实际查看：

1. 正面：构图完整，文字与主体互不遮挡，细节来自本次设定。
2. 左右 ±25°：主体与完整背景相对位移，头发与袖口无矩形切边，背景无第二张脸；层距紧凑，文字钉在卡面。
3. 关闭 foil 仍有内部视差；depth=0 时内部错位消失。镭射随观察方向变化，不只是循环彩虹。
4. 手机拖动、键盘和减少动态行为正常；拖动不误触翻面。

仅有单张插画不算分层完成；把同图重复放进多层也不算。报告应明确模型生成、像素检查和真实视觉检查分别完成了什么。

## 与上游的边界

本仓库改编 RuiC 的视角驱动 UV 视差与 foil 公式，保留 MIT 版权；独立排字和同像素线稿也遵循其流程思路。上游棋盘转换属于修复兜底，本项目按用户要求关闭抠图路线。原生透明不符合要求时重生成或降为静态。

网页呈现的是多平面卡片，不是完整三维人体。没有真实运行上游 Blender 流水线，就不声称交付 `.blend` 或 GLB。
