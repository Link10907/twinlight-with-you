# V10 品质标准与实际验收

当前第一基准是用户指定的 `twinlight-v10` demo。维护时可对照该目录的真实首页、交融、揭卡和左右倾斜截图；生成新用户作品时使用随包固定模板和通用审美参考。旧 demo 的作者资料、卡面文字与人物设定不是新用户输入。

## 哪些稳定，哪些每次创造

| 固定产品表现 | 当前人专属内容 |
|---|---|
| 黑金星系、细衬线标题、克制控件、靠近后出现的行星 | 名称、主题、话题与有依据的叙事 |
| 个人星系与 AI 星系连续靠近、交错、长尾、交融；约 14 秒终章、提问和揭卡 | 实际总结者署名、称号、标语、关键词 |
| 揭卡版式、翻面、音乐开关、保存、返回、手机布局 | 原创主体、一个动作、相应场景与少量象征 |
| 紧凑层内视差、固定文字、随视角变化的 foil 与材质选项 | 插画具体配色与纹样，服从统一收藏卡质感 |

页面用现成模板组装，效果用原 renderer；不重新“创作”星系页面来凑相同功能名称。**构建通过证明来源一致，真实画面与交互检查证明作品仍然成立。**

## 默认美术为什么像 Twinlight

V10 的筑星者是一幅精细幻想插画：人物表情与手势清楚，衣料有褶皱、厚度和纹饰，明暗组织出人物体积；环境、近景和装饰围绕主体形成纵深；较亮的脸与动作先吸引目光，繁复细节随后可读。大称号、SSR 与细金属框和插画组成一张完整收藏卡。

护芽者说明同样的完成度可以换成动物与自然场景：毛发、叶片、花朵、盆器与温室各有材料，前后景的光线层次清楚。可继承的是画面完成度、焦点和质感，不能把鹿、男角色、蓝金月夜或旧故事定成每个人的模板。

因此默认 `twinlight-collector` 不等于“简约”或“所有人长一样”。一个主体、一件事是叙事约束；细节可以丰富。其他摄影、淡墨、极简、剪纸方向只有在用户明确换画风时使用。即使换画风，仍验收完成度、排字、景深和镭射。

## 三次真实观察，分别解决不同问题

**原型：画本身值得做成卡吗？** 打开当前无字原型和所用审美参考，至少观察以下要点；记录可见事实，不只写“精美、符合”。

| 维度 | 通过时能实际指出的内容 | 应退回原型的现象 |
|---|---|---|
| 焦点与动作 | 第一眼能找到主角、脸或关键结构，并看懂正在做什么 | 小主角淹没在特效中；动作混乱；像一堆主题图标 |
| 形体与材料 | 脸/手或动物结构可信；布料、金属、植物等有不同表现 | 塑料脸、糊手、廉价 3D、平面色块；材料全一样 |
| 空间与光线 | 至少能辨出主体与环境前后关系；主光方向一致 | 把人贴在平面底上；无明暗体积；杂乱光圈掩盖结构 |
| 细节层次 | 焦点细致清楚，周边丰富但服从主体；同尺寸下接近参考完成度 | 大面积粗糙、通用模板脸、背景无意义或装饰盖住主角 |
| 卡面可读性 | 顶部标签与底部称号有空间，主角和关键道具不会被挡 | 脸或主动作落在标题区；需用不透明大面板遮住画面 |
| 图层归属 | 能按实际位置点名主体/接触道具、背景、少量近景；近景与人物轮廓清楚分开 | 大面积同色近景与衣摆混在一起；支撑桌台/灯具被误当人物；需多层反复猜归属 |

原生编辑返回的每边 1 像素舍入差可在明确的完整 UV 显示映射下接受，实际源图保持不变；它不等于允许主体缩放、移位或裁头。审美判断看真实构图，而不是为不可见的舍入差浪费重画。

**无字合成：分层后有没有把好画毁掉？** 与已通过原型比较轮廓、比例、朝向、位置、材料和光线。检查完整空背景、干净 alpha、单一道具归属、无重复主角和错误遮挡。合成后明显比原型差就修失败层，不降低审美标准。

**最终正面与互动：它是否是一张完整的 V10 闪卡？** 看当前 front 和实际独立预览，再看最终 HTML 揭卡。大称号与 SSR 有层级，中文准确、缩小后可读，卡框精致，底衬渐变融入插画。左右转动与顶部倾斜时内部有紧凑深度、边缘不露空；foil 随视角变化，文字固定且不被持续彩虹淹没。手机主卡完整、文字与操作可用。

按 review-template 返回的当前 checks 逐项填写。品牌质量检查是实际观察记录，不是模型给自己打一个神奇总分；不声称艺术品每次完全相同，也不声称哈希能判断好看。

## 最终页面体验验收

看首页、进入一个主题与话题、AI 星系介绍、交融中段、提问、正面揭卡、翻面和返回。检查星系流动、近处行星、选中光效、连续转场、卡图与文案以及手机排版。完整播放要持续到揭卡；跳过按钮通过不等于连续动画通过。暂停、跳过、键盘、触摸、减少动态和声音开关按实际能力记录。

原 V10 曾以旧插画重建 alpha 并延拓背景；其画面与交互是品质标准，历史拆层方式和边缘瑕疵不是新生图工序。当前新卡先画出合格原型，再以图像工具原生编辑生成透明层和完整背景，仍使用 V10 的呈现效果。代码不抠图或改坐标；独立重画导致的放大、上移、裁头和背景/前景重复属于需要修复的缺陷。

## 返工与诚实边界

把缺陷落到一个责任对象：模板缺失修资源；粗糙原型修绘画；配准/白边修对应层；文字拥挤修排版；视差/foil 修 renderer 或运行环境。保留已合格结果，不因技术报错重画整套。

每角色首次加最多两次修复，全部计入本次尝试。失败保留真实预览和成功模块，完整卡不计成功。内部记录可以说明 provenance 与审查，但不能替代实际图像质量，也不等于本人公开授权。
