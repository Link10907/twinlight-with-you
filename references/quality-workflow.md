# 当前美术生产流程：明确设计、原生素材、实际观察

当前生产契约是 `art-direction-2`，字段与流程见 `visual-contract.md` 和 `../CARD.md`；旧 art-direction-1/plain brief 只兼容局部诊断。生产要求不是更长的提示词，而是把每一步真正落实。

## 设计与角色复杂度

读取本人的明确偏好与否决项，从四套 style_id/version 选一套。人物、动物和物件都可，但必须有具体物种/外貌和一个可看懂的动作；一个主体、2–5 个外貌特征、最多一个主要道具、简单背景、少量前景，不叠加第二角色。提炼资料中的特征作为选择依据，不把个人履历全画成标志。

编译器派生视觉词与整句形象说明。构图与风格跨层共用，各层内容独立；尤其背景不再接收人物的外貌与道具描述，避免先要求画人物又要求不要人物。

## 三道视觉关口

**prototype**：真实无字图，主体清楚、风格准确、材质与动作可信、轮廓有辨识度、文字有空间。未通过就不生成层。

**composite**：真实原生层 alpha 合成，不是另一张重画海报。核对配准、完整空背景、边缘、单一物件归属、原型一致性与所选画风。

**final**：实际 front + 独立 preview。文字准确、固定、可读；关闭 foil 仍有内部视差，depth=0 后位移消失，恢复 foil 后随视角移动；左右视角、手机、拖动/键盘/减少动态均实际观察。

程序只生成 pending review 模板。宿主实际看图并填写具名观察、捕获记录和当前文件 targets，再用 bind-review 绑定。来源字节/风格/文字/预览变化后旧意见失效；不允许只改哈希继承批准。

## 原图与交付关口

使用 visual_plan compile / record 保存具体提示、实际工具返回、请求/返回尺寸、style版本hash、原型引用和每次尝试。原生透明不等于画了棋盘背景；不裁剪、去背景、重采样、重新摆位或重复整张海报。

每层首次后至多两次额外尝试；失败原图和原因保留。空 subject/effects/text、同图多层、错误 lineart、static 或 placeholder 不得通过完整闪卡交付。空 spirit 是“不另加同伴”的合法选择，不代表空主体可接受。

已通过的卡片由 public run 自动接入。最终 HTML 逐层核对原始字节，而不是只看 manifest 字段。complete 同时需要 public 美术记录、固定模板、原生内嵌和实际浏览器通过；host inline preview 另记。

本地哈希与观察不能认证外部图像服务，也不是客观审美评分或本人公开授权。quality_verified/generation_provenance_verified 保持 false。测试夹具只证明代码行为，不算真实生图成功率。
