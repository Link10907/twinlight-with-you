# 一次请求交付 HTML 与独立闪卡

默认入口自动完成个人单文件 HTML 和独立闪卡，用户无需再发第二条命令。先构建不依赖卡图的基础星系 HTML，再运行独立卡片模块；完整匹配卡包完成后自动用于最终 HTML。仅在用户明确只要其中一个时运行对应模块。编排见 [AGENT.md](../AGENT.md)，内部契约见 [HTML 模块](../prompts/html-build.md) 与 [闪卡模块](../prompts/card-generation.md)。

HTML 必须是固定模板实际构建的个人 `.html` 文件，含当前人的星系、叙事和身份文字；离开工作目录也能直接打开，图片与通用查看器不能代替。闪卡结果包含原生层及清单、便携 `card.json`、独立 `card/preview.html` 和正面 `card/front.png`。独立闪卡预览不读取星系，也不要求 HTML 先成功。

## 检查与预览

交付前核对实际文件、当前 persona、展示内容与内嵌资源。HTML 模块只消费已校验的只读内容与可选成品卡包，不重新生图、改称号、逐字重写数 MB 资源或另写 React 页面；美术设定保存在卡片目录，不注入页面数据。

有浏览器时检查 HTML 载入、AI 星系、个人主星、双星交汇、揭卡与返回；自动接入卡包后核对绑定与显示。原生透明、配准、排字和独立景深/foil 先在 `card/preview.html` 按 [美术契约](art-direction.md) 验收。记录 WebGL/CSS 降级和实际未验证项目，不把截图、文件下载或预览构建成功当成交互已验证。声音可能需用户点击。

`card/front.png` 由 `render-card` 消费已有素材作独立正面预览，不调用生图、不构建星图、不烘焙动态 foil。原型或 raw background/subject pair 不代表完整原生分层已完成；PNG 也不能证明互动景深和闪光已经验收。完整卡片不能仅交付静态图片。

完成消息简短给出实际 HTML 和卡片图片/独立互动预览入口，再打开宿主可用的同一文件预览；用户重点是卡片时先展示卡片。完整卡包、manifest、报告、命令和证据留作附件，用户无需理解 JSON 才能查看。

## 能力、草稿与独立失败

Lite 资料充分时默认完成未确认的私人草稿，如实记录文案尚未确认，保持 `draft=true`、`share_allowed=false`；不能伪造本人批准。已明确确认确切当前文字时沿用真实确认，不重复问。Strict 继续原来的来源核对与本人审阅。草稿和文案确认都不授权发布。

卡片失败只修卡片，保留成功的基础 HTML；原型或占位明确标为卡片未完成，不能将整体说成完整闪卡交付。HTML 失败只修构建或导入，保留已经完成的独立卡片与预览；不重新生图或改文案。匹配卡包的导入失败保留基础 HTML，不用另一人的绑定冒充。入口在本次请求内继续自修，交付实际完成的结果和具体未完成部分，不让用户另提生成命令。

网页聊天有文件/代码工具就完成同一构建。明确没有文件/执行工具时，报告具体缺口与任务未完成，坦诚不能保证一步完成；不默认改成图片或 JSON。只有用户选择手动查看器导入时才交付所需内容和素材，导入后仍须取得这个人的完整 HTML。宿主 AI 的模型处理不因此变成离线。

## 本地打开

单文件内嵌 CSS、JavaScript、图像、纹理与音频，现代浏览器直接打开即可；观看不需 Node.js、Python、API Key 或服务器。生成需项目构建环境，由 AI 处理。分享 HTML 或卡包会带走其中的个人内容与图像，不自动授权公开。

宿主预览能力须实际检查。项目尚未完成 ChatGPT 网页真实账号端到端验证；本地检查不能充当宿主认证。OpenAI 的 [HTML 预览说明](https://learn.chatgpt.com/docs/artifacts-viewer) 也不保证任意账号可执行本模板。

预览工具若只接受 HTTP，可在仅含待预览 HTML 的目录启动绑定 `127.0.0.1` 的临时服务，不服务私人历史或分析目录；无需为观看自动部署网站。
