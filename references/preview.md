# 交付每个人独立的 HTML

最终工件是固定模板实际构建的个人单文件 HTML，内含当前人的星系、叙事和身份文字，卡图仅从完成的闪卡包导入。离开工作目录也能直接打开；图片与通用查看器不能代替该文件。详细执行见 `AGENT.md`。

## 检查与预览

交付前核对文件存在、当前 persona 与内容一致、图像/样式/脚本已内嵌。不能由模型逐字重写数 MB 资源，也不能用另一张简化网页代替模板输出。

有浏览器时检查载入、AI 星系、个人主星、双星交汇、揭卡与返回；导入已有卡包时核对绑定与显示。美术生成和验收留在独立闪卡流程，主流程不读取美术契约。记录 WebGL/CSS 降级以及实际未验证项目，不把截图或文件下载当已运行交互。声音可能需要用户点击。

先给 HTML 的真实附件/有效文件链接，再用宿主实际可用的 HTML/Artifact 预览打开同一文件；没有预览也提供该文件。卡片是用户重点时可先展示 HTML 内的卡片。完整报告、manifest、命令与证据留作可选附件。

## 能力与草稿

网页聊天有文件/代码工具就完成同一构建。仅有聊天或生图工具、无法构建时，报告具体缺口与任务未完成，不默认改成图片或 JSON。仅在用户明确选择手动查看器导入时交付所需内容和素材；导入后还要下载这个人的完整 HTML。

未导入卡包时 HTML 可以独立完成，艺术卡如实标为占位。原型静态卡 depth=0，不能宣称闪卡流程已完成；制作或修复卡包回到 `CARD.md`。不能伪造本人批准、下载链接、执行或验证结果。

## 本地打开

单文件内嵌 CSS、JavaScript、图像、纹理与音频，现代浏览器直接打开即可；观看不需 Node.js、Python、API Key 或服务器。生成需项目构建环境，由 AI 处理。分享该 HTML 会带走其中的个人内容，不自动授权公开。

宿主预览能力必须实际检查。项目尚未完成 ChatGPT 网页真实账号端到端验证；本地检查不能充当宿主认证。OpenAI 的 [HTML 预览说明](https://learn.chatgpt.com/docs/artifacts-viewer) 也不保证任意账号可执行本模板。

预览工具若仅接受 HTTP，可在仅含待预览 HTML 的目录启动绑定 127.0.0.1 的临时服务，不服务私人历史或分析目录；无需为观看自动部署网站。
