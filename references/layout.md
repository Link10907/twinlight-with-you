# 数量与排列

**主星 = 一条有证据的稳定主题；行星 = 主题内的可区分记录簇。** 粒子与星尘只是装饰，数量不代表用户有那么多经历。

主题 ID 使用稳定小写语义标识，例如 `building-systems`。不能用标题翻译、数组位置、模型自拟新措辞或生成时间作为 ID。主题没有新事实时沿用 ID；合并/拆分要记录映射。owner ID 采用不含真实姓名/邮箱的稳定 pseudonym，避免暴露身份。

支持 1–8 主星、每主星 0–8 行星。建议有证据时 3–6 主星，每组 2–6 行星，但这只是视觉建议，不是凑数要求。频繁重复问一个问题先去重为一组；少量真实记录宁可留白。

`layout.py` 对语义 ID 排序，SHA-256 产生稳定候选角度/半径/颜色。主星之间设定最低空间距离；行星各自具有不同轨道半径、相位、倾角、偏心率和大小，不全部挤在一圈。速度由轨道半径规则计算。这里是艺术编排，不是天体物理计算，3D 分离也不保证任意镜头二维投影绝不遮挡。

增量提供 `--layout-lock` 时，保留现存 ID 的全部位置与参数，只给新对象分配位置。旧对象删除后，剩余对象不重新洗牌。空间耗尽或数量超限即失败；需人同意合并主题或显式重排，不能悄悄截断。

尺寸只弱关联去重后的相关会话数量，上限很小。它不衡量重要程度、能力或价值；SSR 永远一致。首页光点为主；局部行星才展示材质和轨道，默认标签少，鼠标/轻触/键盘聚焦再展开。

当前 V10 衍生模板支持编译和运行时导入 1–8 主题。运行时导入清除旧卡的可用状态和分享许可；不能把旧照片/旧评价拿给新用户。要有新图必须重新构建。
