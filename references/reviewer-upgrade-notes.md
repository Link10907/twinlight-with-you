# 独立审查升级说明

本次只改制作/审查/交付控制，不修改 V10 的 renderer、星系、shader、揭卡动画或画风参考。没有重新生成任何个人闪卡，没有启动一个不存在的第二 Agent。

新增 REVIEWER.md、independent_review.py、reviewer.py。原型/合成/独立预览审查检查不同会话与当次原始响应；public run 在最终集成后强制等待 release 审查；export 再检查当次报告、文件和 foil/depth 受控截图。缺失、驳回、自签、旧文件、降级未验证、参数无画面变化都不能完整放行。

真实独立任务由宿主执行，平台凭据/会话 ID/OS 只读不再是运行前提；本包不捆绑 API 密钥、不安装新服务、不调用付费模型。本地 trace 仅检查一致性，不防同权限生产者伪造身份。任务须保持独立上下文；无 OS 沙箱时如实记录并核对输入未变，不作安全认证保证。

新回归用例使用明确标为 SYNTHETIC 的合成文件和调用记录，仅测试阻断逻辑；不证明新闪卡画风、实际 WebGL 或端到端视觉质量已通过。
