# 按能力接入不同 AI 平台

共用同一内容契约、固定模板、`run` 控制器与独立美术契约。平台适配只负责输入文件、执行工具、图像返回与预览入口，不另写一套页面或改变人物分析。ChatGPT 网页、Claude 网页、Codex、Cursor 及其他宿主均先检查本次真实能力；平台名称、模型自述或能读取 GitHub URL 不等于有完整执行环境。

## 最小能力与路线

| 当前能力 | 本项目实际可走的路线 | 交付边界 |
| --- | --- | --- |
| 文件读写、Python 3.10+ 与依赖 | 上传完整资源包或 bootstrap 获取同一 revision，调用 `run` | 可以构建固定模板 HTML；浏览器、生图仍分别检查 |
| 上述能力及实际生图、参考图和原生透明输出 | 独立卡片模块生成原型与层，`run --layers` 自动续跑接入 | 可完成分层卡文件，视觉与互动仍须实际验收 |
| 可执行但缺生图或原生透明输出 | 先交付已验收 HTML，保留已有静态预览与卡片待办 | 专属原生 SSR 尚未完成，不能代码画图凑齐 |
| 文件可上传下载但无代码执行 | 当前无法自动执行 Python 构建器 | 不声称已生成个人 HTML；手动查看器仅在用户选择后使用 |
| 只能聊天文本 | 可协助整理有依据的内容，无法执行完整产物链 | JSON 或文字不算已经请求的 HTML 和分层卡 |

本轮没有部署网页构建服务、MCP 服务或自动接入网关。以后可将同一控制器封装为获授权的远程工具，让有工具调用但没有本地 Python 的宿主使用；部署、连接和真实测试完成前，不把该候选路线写成已经可用。不要为一次生成新建无关账号、自动付费 API 或公开上传个人资料。

## 宿主执行者自行检查

1. **资源与文件**：能否解包/下载完整项目、读取同版文档、保存并返回真实工件；用 bootstrap 检查目录与模板锁。资源缺失时不自由重写页面。
2. **执行**：实际 Python 版本、`requirements.txt` 依赖和允许输出目录；需要修复时由 AI 在当前授权环境处理并重查。
3. **图像**：当前会话确有可调用工具，能使用同一原型参考、返回合法 3:4 全画布及原生透明 PNG。能生成图片但不能透明输出时，只能保留静态原型预览。
4. **排字**：生成前确认可用中文字体；`run` 对待生成卡片预检字体可加载，支持 `--font <真实字体文件>`，已完成文字层无需重新排字。`prepare_card_layers.py` 同样支持自动查找或 `--font`。字体可加载不证明每个中文字形覆盖，最终仍逐字看成品；缺字体时由 AI 修排字环境，不让图像模型画 SSR、中文或署名。
5. **运行预览**：浏览器是否允许完整 JavaScript、WebGL、音频与本地附件；有实际 Chrome/Chromium 时传 `--browser`。没有时保留文件核验、使用 `--no-browser`，明确动态未验证。

不向用户发工具问卷。上述检查属于 AI 的内部执行责任；无法自行解决的具体缺口用一句话报告，已完成结果仍保留。

## 文件生成与站内观看分别判断

创建可下载 HTML 不保证 AI 网站的附件预览能执行全部脚本。宿主支持时打开实际文件；受限时返回真实附件或链接，用户可在现代浏览器直接打开。观看已构建单文件无需 Node.js、Python 或服务器。仅接受 HTTP 的预览工具可以使用只服务待预览文件、绑定 `127.0.0.1` 的临时服务；不服务私人历史目录，也不自动部署。

仓库现有浏览器查看器是手动导入兼容路线，尚不是自动分析、生图、组装服务。用户明确选择它时才使用，并保留真实生成与验收边界，不算默认一次请求路线已完成。

## 平台验收

分别记录宿主、实际模型/工具、资源获取方式、原始资料、完整一次请求和实际工件。按 [fresh-generation-eval.md](fresh-generation-eval.md) 验证当前接入，区分文件完成、动态通过、卡片质量与整体完成。某一本机试验或平台通过不代表其他平台认证；失败、缺工具和未测试均保留，不以品牌列表替代实测。
