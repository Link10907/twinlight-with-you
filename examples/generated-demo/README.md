这个演示使用完全虚构的“小禾”：照料阳台植物、观察画和阅读短记。她的“护芽者”卡由本项目的通用轻量流程生成，角色是原创鹿形守护灵，不包含作者经历。

原型直接生图。主体、背景和前景分别参考原型重新生成；透明层由生图工具原生输出，没有抠图、绿幕、棋盘转换、裁切、重摆或缩放主体。各层完整画布均为 1086×1448；这是生图工具实际输出的原始尺寸。文字/SSR/卡框独立排版，未使用伴生角色时 spirit 为透明画布，lineart 从最终主体的 alpha 轮廓派生。

- `twinlight.json`：虚构用户内容。示例只能演示，不能参与新用户分析。
- `prototype.png`：无字原型，仅作共同构图参考。
- `card/layers.json`：绑定当前卡面资料的清单。
- `card/flat.jpg`：查看效果的合成图，不能替代独立图层。
- `provenance.json`：来源、制作方式及资产哈希。

在已安装项目 Python 依赖的环境运行：

```sh
python3 scripts/twinlight.py demo --out outputs/demo
```

直接打开生成的 `index.html` 即可观看，不需要 Node.js。原生生图会出现与原型略有不同的细节，真实用户交付时仍需检查构图、边缘和文字。演示的虚构数据不证明模型对真实历史的分析准确度。
