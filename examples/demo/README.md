# 完全虚构的示例

小岚不是用户本人，所有消息均为人工编写的测试素材。例子包含助手夸奖、第三方、假设、未开始的计划、实际尝试和无日期记录，用于验证不会混写。

`history-input.json` 是可公开的虚构输入；`profile.json` 是可公开的虚构展示 JSON。默认个人使用 ZIP 不包含本目录；需要演示时使用源码或 `--include-demo` 的单独演示包。真实用户分析不得从本目录改名、续写或补全；资料不足时明确返回缺口。

`analysis.json` 的 GPT 表示本次制作这一虚构示例的总结来源；没有杜撰具体模型版本。实际用户运行必须由真实宿主元数据赋值。

原始 fixture 可以公开只是因为它全部虚构。真实用户的相同文件结构必须留在 private/。程序星盘仅用于独立图层/视差测试，不是为某个用户生成的角色成品。
